Fallout Character Randomizer
------------------------

Don't know what kind of character to make? Fear not: at the start of a new game, this mod will roll a completely unique character for you. Will that character be good? Probably not. Will you have a unique playthrough? Maybe. Perfect for a semi-iron man playthrough!

This mod is only compatible with Fo2 + Sfall. CE is not supported.

### Installation
To use this mod, add the mod folder name to the mods_order.txt file inside the /mods/ directory. If the mods_order.txt doesn't exist, start the game once for it to be created.
